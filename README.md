# RP Image Chat

AIとのロールプレイ会話と、ComfyUIによる場面画像の生成を一つの画面で楽しむためのシンプルなチャットアプリです。PCのブラウザのほか、同じLANにつないだスマホからも使えます。

## 主な機能

- キャラクターや舞台の設定を分けられる複数チャンネル
- 過去の発言の編集、AI応答の改変と再生成
- チャンネルごとに選べるRAG知識ベース
- 画像の自動生成、別シードでの再生成、画像履歴と背景表示

ユーザーの入力はPC上のセッションファイルに保存されます。AIとのやり取りは`wait_input.py`と`outbox/`のJSONファイルを介して行います。AIエージェントとComfyUIは別途用意する構成です。

このリポジトリにはアプリのソースコードだけを置いています。会話履歴やRAGデータは含まれていません。
