# RP Image Chat

Antigravity の AI とロールプレイのチャットをしながら、場面の画像を ComfyUI で自動で作るローカルアプリです。

## 使い方

### 用意するもの

- Windows
- [Python](https://www.python.org/downloads/) 3.10 以上。インストールの最初の画面で **Add python.exe to PATH** にチェックを入れてください（ほかに入れるものはありません）
- [Antigravity](https://antigravity.google/)（返事を書く AI）
- [ComfyUI](https://github.com/comfyanonymous/ComfyUI) とチェックポイント（画像を作るときだけ。文章だけなら要りません）

### 1. ダウンロードする

このページの **Code → Download ZIP** で落として展開するか、`git clone` します。
置き場所はふつうのフォルダにします（例: `D:\rp-image-chat`）。OneDrive の中や `Program Files` は避けてください。
ComfyUI と同じ階層に置くと、ComfyUI の出力フォルダ（`..\ComfyUI\output`）が自動で見つかります。

### 2. 起動する

1. Antigravity を起動しておく
2. 画像を使うなら ComfyUI も起動しておく
3. フォルダの中の **`start.bat`** をダブルクリックする。黒いウィンドウが開きます。アプリを使っている間は閉じないでください
4. ブラウザで <http://127.0.0.1:8200/> を開く

スマホから使うときは、`start.bat` の代わりに **`start_mobile.bat`** をダブルクリックします（下の「スマホから使う」を参照）。

### 3. チャンネルを作る

サイドバーの **＋** を押します。Antigravity に新しい会話が自動で作られ、そのチャンネルの担当になります。

最初からある「チャンネル1」にも、Antigravity の新しい会話が自動で付きます。Antigravity を後から起動した場合は、起動したときに付きます。

### 4. 話しかける

メッセージを送ると、2 秒後に担当の Antigravity 会話へ合図が届き、AI が返事を書きます。
返事に画像の指示があれば ComfyUI で画像が作られ、チャットに表示されます。

Antigravity で自分から話しかける必要はありません。最初の合図では、AI が実行するコマンドがアプリから送られます。2 回目からの合図は半角スペース 1 文字です。
Antigravity でコマンドの実行やファイルの書き込みの許可を聞かれたら、許可してください。

### 5. 好みに合わせて設定する

**設定** でチャンネルごとに次のものを決められます。

- System ファイル・参考ファイル・読ませるファイル（キャラ設定や世界観など）
- 画像キャラの見た目タグ
- キャラの状態と内心を記録するか（下の「キャラの状態と内心」を参照）
- 画像設定。`checkpoint` は自分の ComfyUI にあるファイル名に変えてください

## 概要

```text
ブラウザ ──発言──▶ server.py ──合図──▶ Antigravity の会話
   ▲                  │                     │
   │                  │◀── wait_input.py で発言を受け取る
   │                  │◀── outbox/ に返事の JSON を書く
   └──返事・画像──── server.py ──▶ ComfyUI（画像）
```

- **AI は Antigravity が担当します。** このアプリは発言を渡して返事を受け取るだけで、AI のログインや API キーは扱いません。
- **待っている間は使用量を使いません。** AI は返事を書いたらターンを終え、次の発言の合図が来るまで止まっています。
- **会話と巻き戻しが連動します。** チャットで発言を編集・削除・作り直しすると、Antigravity の会話もそこまで巻き戻ります。分岐すると会話も分岐します。
- **データはこの PC にだけ残ります。** 会話・知識ベース・返事は `data/` と `outbox/` に保存されます。消した物は `data/trash/` に残ります。

## スマホから使う

1. `start_mobile.bat` をダブルクリックして起動する
2. PC のブラウザで <http://127.0.0.1:8200/> を開き、**設定 → スマホで開く** を開く
3. 同じ Wi-Fi につないだスマホのカメラで、そこに出る QR コードを読む

QR コードの下にはアドレス（`http://192.168.x.x:8200/` のような形）も出ます。黒いウィンドウにも同じアドレスが出ます。

初めて起動したときに Windows のファイアウォールの確認が出たら、**プライベート ネットワーク** を許可してください。

**このモードにはパスワードがありません。** 同じネットワークの機器なら誰でもチャットを読み書きでき、通信も暗号化されません。自宅の Wi-Fi など信頼できるネットワークだけで使い、公衆 Wi-Fi では使わないでください。

## Antigravity 以外の AI で使う

合図・巻き戻し・分岐は Antigravity 専用です。ほかの AI エージェントでも、次の手順なら返事を書かせられます。

1. チャンネルに担当の会話を付けない
2. 発言を送ったら、AI に `python wait_input.py` を実行させる
3. AI が表示のとおり `outbox/` に返事を書く
4. 次の発言を送るたびに、AI に知らせる

## 詳しい説明

### 会話を選ぶ・作る

- **会話を選ぶ…**: Antigravity の会話をフォルダごとに新しい順で出します。タイトル・フォルダ・ID で検索でき、会話 ID を直接入れることもできます。一覧は `~/.gemini/antigravity/conversation_summaries.db` を読み取り専用で読んでいます。
- **新規会話**: Antigravity に空の会話を作って担当にします。何も送りません。会話のフォルダは `session`（全チャンネル共通）です。そのフォルダの Antigravity プロジェクトがなければ作ります。
- **外す**: 担当を外します。会話そのものは消えません。
- ほかのチャンネルが使っている会話を選ぶと、入力が同じ会話に集まるので、確認してからつなぎます。
- **＋** で会話を自動で作らないようにするには、**アプリ全体の設定** の「新しいチャンネルには Antigravity の新規会話を自動で作る」を外します。

### 合図

- 発言が 2 秒たっても受け取られていなければ、担当の会話に半角スペース 1 文字を送ります。AI はそれを合図に `wait_input.py --ide <会話ID> --wait 30` を実行して発言を受け取ります。
- その会話に初めて合図するときは、スペースではなく実行するコマンドそのものを送ります。スペースを送って 30 秒たっても受け取られないときも、1 回だけコマンドを送り直します。
- 合図は会話 ID を指定して Antigravity の言語サーバーに直接送ります（`SendUserCascadeMessage`）。ウィンドウやフォーカスは使わず、ほかの会話にも影響しません。AI が返事を書いている間は送らず、終わるのを待ちます。
- **今すぐ合図** で、すぐにコマンドを 1 回送れます。
- `python ide_poke.py --status <会話ID>` で、何も送らずに会話の状態を確かめられます。

### モデル

入力欄の上の **モデル** で、合図で始まるターンのモデルを選べます。一覧と残りの利用枠は Antigravity から読みます。「会話の最後の入力と同じ」（初期値）は、その会話で最後に使ったモデルをそのまま使います。Antigravity の画面で自分で打ったターンには影響しません。

### 返事を書いている間の表示

担当の会話が返事を書いている間、チャットに AI が今していること（実行中のコマンドや読んでいるファイルなど）を表示します。2 秒ごとに会話を読むだけで、会話は変えません。

### 巻き戻し・分岐

- 発言の編集・削除・作り直し・「ここまで戻す」をすると、担当の会話もその前のターンまで巻き戻します。巻き戻す前の会話データは `data/trash/ide_revert/` に写します。AI が書き換えたファイルは戻りません。チャンネル設定でオフにできます。
- 発言の **分岐** で、そこまでの会話で新しいチャンネルを作り、担当の会話もそこで分岐します。
- 1 回のターンで AI が入力を複数受け取っていたなど、ちょうどよい位置が決まらないときは巻き戻し・分岐をせずに理由を表示します。

### AI に渡す内容

- 担当の会話が前回と同じなら、増えた発言と変わった設定だけを渡します。担当が変わったとき・過去を書き換えたとき・**次は全部送る** を押したときは全部渡します。
- チャンネル設定の「入力の渡し方」を **今回の発言だけ** にすると、全部渡すときも直近 15 件だけを全文で渡し、それより前は AI メモで補います。
- 長い内容は Antigravity が途中を省くので、`data/ctx/` にファイルとして書いて場所を渡します。
- **入力のたびに最後にルールを付ける** をオンにすると、追加のルールを毎回いちばん最後に付けます。
- **AGENTS.md** をオンにすると、作業フォルダに System ファイルと追加のルールを `AGENTS.md` として書き出します。

### 応答の書き方

`wait_input.py` が表示した `session` と `reply_to` を使って、`outbox/<任意の名前>.json` に UTF-8 で書きます。

```json
{
  "session": "<チャンネルID>",
  "reply_to": "<発言ID>",
  "text": "返事の本文",
  "memo": "あらすじのメモ（任意）",
  "image": {
    "prompt": "2girls, smiling, cafe",
    "characters": ["アリス", "ベス"],
    "width": 896,
    "height": 1152,
    "raw": false
  },
  "characters": [{"name": "アリス", "tags": "blonde hair, blue eyes"}],
  "state": [{"name": "アリス", "situation": ["カフェの窓際に座っている", "紅茶を持っている"], "inner": "少し緊張している"}]
}
```

- `image` は任意です。`raw: false` なら、チャンネルの基本プロンプト・共通タグ・`image.characters` のキャラの見た目タグを前に付けます。`raw: true` なら書いたとおりに使います。
- `characters` はキャラの見た目タグを登録・更新します。画面でロックしたキャラは上書きしません。
- `state` は、チャンネル設定の **キャラの状態と内心を記録する** がオンのときだけ使います。キャラごとの今の状態（`situation`、箇条書き）と内心（`inner`）です。書いたキャラの、書いた項目だけが変わります。`{"name": "…", "remove": true}` でそのキャラを消します。

### キャラの状態と内心

チャンネル設定の **キャラの状態と内心を記録する** をオンにすると、AI は返事のたびに、場面に出ているキャラの状態と内心を `state` に書きます。

- 次の入力を受け取るたびに、前の返事のときの状態を毎回 AI に渡します（差分で送るときも渡します）。
- 状態は返事ごとに残るので、編集・作り直し・巻き戻し・分岐をすると、そのときの状態に戻ります。
- 返事の下の **📋 状態** で見られます。返事の **状態** ボタンで直せます。直した内容は次の入力で AI に渡ります。

### 主な機能

- プロジェクトごとにまとめた複数チャンネル、絞り込み、書き出し・取り込み、分岐、複製
- System ファイル・参考ファイル・追加したフォルダから選ぶ読ませるファイル（`.md` / `.txt`、プリセット付き）
- 画像キャラの見た目タグ（全チャンネル共通のプリセット付き）
- キャラの状態（箇条書き）と内心の記録
- 発言の Markdown 表示、編集・作り直し、返事の書き換え
- 発言にファイルを添付（📎・貼り付け・ドロップ）。画像は Antigravity のチャット欄にも貼られます
- 知識ベース（RAG）をチャンネルごとに選んで使う
- 画像の履歴、シード違いの作り直し、プロンプトの編集、スクロールに合わせて背景に画像を出すモード

### 環境変数

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `COMFYUI_URL` | `http://127.0.0.1:8188` | ComfyUI の API のアドレス |
| `COMFYUI_OUTPUT_DIR` | このフォルダから見た `../ComfyUI/output` | ComfyUI が画像を保存するフォルダ |
| `RPCHAT_PORT` | `8200` | チャットのポート（`wait_input.py` は起動中のサーバーのポートを自動で使う） |
| `RPCHAT_HOST` | `127.0.0.1` | 待ち受けるアドレス。`lan` で PC の LAN アドレス |
| `RPCHAT_NEW_IDE_DIR` | このフォルダの `session` | **新規会話** で作る会話のフォルダ |
| `RPCHAT_ALLOWED_HOSTS` | なし | アドレス欄で受け付けるホスト名を足す（カンマ区切り）。`localhost`・`127.0.0.1`・PC の名前とアドレスは常に受け付ける |

PowerShell での指定例:

```powershell
$env:COMFYUI_OUTPUT_DIR = 'D:\ComfyUI\output'
python .\server.py
```

System ファイルのフォルダ（初期値はこのフォルダの `systemfiles`）と、読ませるファイルのフォルダは、チャンネルの **設定** の「設定ファイル」「読み込むファイル」の欄で選びます。**変更…** や **＋ フォルダを追加** を押すと、PC の画面にフォルダを選ぶウィンドウが出ます。どちらも全チャンネル共通で、`data/settings.json` に保存します。

### 注意

- 同じフォルダでサーバーを 2 つ起動しないでください。2 つ目はポートが違っても終了します（同じ `outbox/` の返事を取り合うため）。
- AI に `wait_input.py` をバックグラウンドで動かし続けさせないでください。受け取った発言を誰も読めなくなります。
- サーバーは自分のホスト名あての要求だけを受け付け、ほかのサイトからの API 要求は断ります（`Host`・`Origin`・`Sec-Fetch-Site` を確認）。開いたウェブページがブラウザ経由でチャットを読み書きすることはできません。
